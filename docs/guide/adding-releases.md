# Adding releases

Select **Add a release** from the library page. The dialog has two tabs: **Search** (MusicBrainz) and **Manual**.

## Search MusicBrainz

1. Type an artist, album or barcode in the search box.
2. Paste an 8–14 digit barcode to match a specific edition.
3. Pick the release from the results.
4. Review the edition, then set what matters to you:
   - format and condition
   - rating
   - purchase date, shop, price and currency
   - genres and notes
5. Select **Add to collection**.

A release already in your library is rejected as a duplicate. If you own a different pressing, search for that edition instead of editing the existing one.

## Enter a release manually

Use the **Manual** tab when MusicBrainz has no match or you are cataloging a private pressing.

Fill in at least title, artist and format. Year, cover URL, genres, condition, rating, notes and purchase details are optional. Sleeve uses your default format, condition and currency from Settings.

## Fix missing metadata

The library shows a **records missing metadata** banner when a record has no MusicBrainz ID, cover or track count.

- **Download metadata** scans the library and matches records conservatively. Low-confidence matches are skipped.
- Open a release and use **Search match** to choose the correct MusicBrainz release yourself.
- **Refresh metadata** re-downloads details for a release that already has a MusicBrainz ID.
- A missing cover is often a Cover Art Archive gap. Try another edition before assuming the match is wrong.

Metadata updates change covers, labels, IDs and tracklists. Your condition, rating, notes and purchase fields are preserved.

## Remove or clear

- Delete one release from its detail page.
- **Settings → Danger zone → Clear library** removes every release and track but keeps wishlist, saved finds, follows, preferences and caches. Type `DELETE` to confirm.

Download a backup first.
