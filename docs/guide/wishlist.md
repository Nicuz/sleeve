# Wishlist

The wishlist is for records you want to buy. It is separate from the library and from Discover saves.

## Add a want

1. Select **Add to wishlist**.
2. Search by artist, album or barcode.
3. Pick the edition and select **Add**.

MusicBrainz supplies the cover, year, label and format. You can add records you already own elsewhere; the search marks items already in the library.

## Set a target price

Select a wishlist card to edit it. Each item can have:

- target price
- currency
- notes

Leave the price empty when you have no target. The header shows the combined target when the list uses one currency, or the number of currencies otherwise.

## Manage the list

- Search and sort by recently added, artist or target price.
- Switch between grid and list.
- **Add to library** opens the edition picker, then creates a real release.
- **Remove** asks for confirmation and deletes the wishlist item.

## Wishlist vs saved finds

| Surface | Meaning |
| --- | --- |
| Wishlist | Buy intent. You plan to hunt this down. |
| Saved finds | Discover bookmarks. You want to keep the suggestion around. |

Saving a Discover card does not add it to the wishlist. Use **Add to wishlist** in the suggestion dialog for that, or promote a saved find later.

Deleting a release from the library never deletes a wishlist item.
